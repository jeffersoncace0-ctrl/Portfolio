# 🌐 Personal Portfolio Website

This project is a **personal portfolio website** designed to showcase my profile, skills, and projects as a developer in training. It highlights my journey in web development, combining clean design, responsive layouts, and interactive features.

##  Overview

The website consists of multiple sections that present personal information, project experience, and additional content such as a pets gallery. It is built using core web technologies and follows a structured and maintainable approach.

---

## Features

### About Me

* Personal introduction
* Academic background (Business Administration & Industrial Engineering)
* Current learning path in web development
* Dynamic text that changes with user interaction

### Projects

* Links to GitHub repositories
* External resources (Google, RIWI platform, etc.)
* Organized grid layout for better visualization

###  Pets Gallery

* Separate page (`pets.html`)
* Responsive grid layout
* Cards displaying images and descriptions of pets

### Contact Form

* Input fields with validation
* Name, email, and message fields
* Clean and user-friendly design

### Interactivity (JavaScript)

* Welcome alert on page load
* Button to dynamically change text content
* Toggle button to show/hide additional information

### Responsive Design

* Mobile-first approach
* Adaptive layouts using CSS Grid and Flexbox
* Optimized for:

  * Mobile devices
  * Tablets
  * Desktop screens
